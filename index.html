HTML Beginner Level

What is HTML?

HTML (HyperText Markup Language) is the standard language used to create and structure web pages. It consists of a series of elements, or tags, that define different parts of a webpage, such as headings, paragraphs, images, links, and tables. HTML works alongside CSS (Cascading Style Sheets) for styling and JavaScript for interactivity.


HTML documents follow a structured format, beginning with a <!DOCTYPE html> declaration, followed by an <html> element that contains the <head> and <body> sections. The <head> section includes metadata, while the <body> section holds the visible content of the webpage. Common tags include <h1> to <h6> for headings, <p> for paragraphs, <img> for images, and <a> for links.


HTML is essential for web development, as it provides the foundation for all web pages. It is a markup language rather than a programming language, meaning it defines the structure rather than executing functions. Modern HTML5 introduces new features like semantic elements (<header>, <article>, <section>), multimedia support (<audio>, <video>), and better form controls to enhance user experience and accessibility.



History of HTML


  • 1991 – HTML 1.0

    • Created by Tim Berners-Lee.
    • Basic tags: headings, paragraphs, lists, links.
    • Used for simple web pages.

  • 1995 – HTML 2.0

    • Standardized by IETF (Internet Engineering Task Force).
    • Included forms and basic structure elements.

  • 1997 – HTML 3.2 & HTML 4.0

    • Developed by W3C (World Wide Web Consortium).
    • HTML 3.2 added support for scripting (JavaScript).
    • HTML 4.0 introduced CSS support, better structure (e.g., <div>, <span>), and internationalization.

  • 1999 – HTML 4.01

    • Minor revision; bug fixes and refinements.

  • 2008 – HTML5 (Draft)

    • Developed by WHATWG and later adopted by W3C.
    • Modern web features: audio/video support, canvas, local storage, semantic elements (<article>, <section>, etc.).

  • 2014 – HTML5 Finalized

    • Became the new standard.
    • Designed for mobile-friendly, interactive, and rich media content.

  • Present – Living Standard

    • HTML is now continuously updated by WHATWG.
    • New features added progressively (e.g., <dialog>, improved accessibility).
